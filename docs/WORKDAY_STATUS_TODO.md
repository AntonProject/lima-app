Фактический ответ `GET /api/WorkDay/status`:

```json
{
  "is_started": false,
  "is_completed": false,
  "start_time": null,
  "end_time": null,
  "day_type_id": null,
  "day_type_name": null,
  "is_late": false,
  "duration": null
}
```

Фактические типы рабочего дня:

1. `Обычный день` — `Визиты к врачам и в аптеки`.
2. `Больничный` — `Не планируются визиты`.
3. `Работа в офисе` — `Административная работа`.
